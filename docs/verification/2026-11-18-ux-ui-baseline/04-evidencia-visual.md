# Evidencia visual del estado inicial

Las capturas en `screenshots/` corresponden al build de producción servido localmente con gzip y proxy a API real en PostgreSQL `_test`. Las capturas en `e2e-screenshots/` proceden de la suite E2E (Vite dev), con sus fixtures y mutaciones reales de prueba. No mezclar ambos grupos al comparar rendimiento.

Los nombres `admin-...-ingresar/recuperar` identifican la serie de recorrido; esas dos rutas se capturaron sin sesión. `dark-preference` significa preferencia oscura del navegador; la aplicación actual sigue mostrando su tema claro. Las capturas no representan un tema oscuro implementado. `controlled-loading/error` son inyecciones de red explícitas.
